# Homebrew Tap

Custom Homebrew tap for my macOS applications.

## Installation

```bash
brew tap izo/tap
```

## Available Casks

### Jean Claude

Menu bar app for monitoring Claude Code Homebrew updates.

```bash
brew install --cask jean-claude
```

**Features:**
- Automatic update checking (hourly/daily)
- Native macOS notifications
- One-click `brew upgrade claude-code`
- Desktop widget support

[View on GitHub](https://github.com/izo/Jean-Claude)
